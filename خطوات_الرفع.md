# GitHub Upload Guide

Follow these simple steps to push your current local changes to the GitHub repository.

## Step 1: Initialize Git (If not already done)
Open your terminal in the project folder and run:
```bash
git init
```

## Step 2: Link to GitHub Repository
Add the remote origin URL:
```bash
git remote add origin https://github.com/adaikamohammed/Al-Shafi-i-Group.git
```
*Note: If you already added the remote, ignore this step.*

## Step 3: Stage Your Changes
Add all modified and new files to the staging area:
```bash
git add .
```

## Step 4: Commit Your Changes
Save your changes with a descriptive message:
```bash
git commit -m "Update project with latest changes"
```

## Step 5: Push to GitHub
Upload your local commits to the `main` branch on GitHub:
```bash
git push -u origin main
```

---

### Troubleshooting: If Push Fails (Force Push)
If the remote repository has changes that you don't have locally (like a README or License created on GitHub), use this command to overwrite the remote with your local version:
```bash
git push -f origin main
```

### Troubleshooting: Large Files / Network Issues
If you encounter network timeouts, set a larger buffer size before pushing:
```bash
git config --global http.postBuffer 524288000
git push -u origin main
```
